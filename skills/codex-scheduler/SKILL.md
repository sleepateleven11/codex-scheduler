---
name: codex-scheduler
description: 在 Codex 桌面中管理向已有对话发送消息的定时任务，选择项目、模型和发送时间，查看或调整等待额度恢复的队列。适用于用户明确请求使用本插件安排或管理发送；普通定时提醒仍使用 Codex 原生定时工具。
---

使用本插件的 `codex_scheduler` MCP 工具管理本地队列。发送通过 Codex 自带的桌面工具服务继续原对话，支持任务指定的模型与思考强度。

- 用户要打开管理器：调用 `scheduler_open`，然后使用 Codex 的 `open_in_codex` 工具，以 `target: {type: "browser", url: 返回的 URL}` 打开它。工具不可用时，提供可点击的返回链接。
- 用户要安排发送：通过 `scheduler_catalog` 获取当前项目和模型，用 `scheduler_threads` 查找所选项目中的已有对话。保留实际 ID；相似标题或多个项目路径不能凭名称猜选。
- 已确定项目、已有对话、模型、消息内容和发送条件后，用 `scheduler_create` 保存。默认 `sendMode: "scheduled"`，按用户时区传入带时区的 ISO 发送时间；用户明确要求额度恢复或可用后发送时，用 `sendMode: "quota_available"`，无需 `runAt`，并说明每 30 秒检测、当前额度可用也会发送。缺少其他必要信息时只询问缺少的内容。创建成功后报告实际保存的触发条件和目标对话。
- 用户明确授权持续重复发送时，才用 `sendMode: "quota_cycle"` 创建额度循环，无需 `runAt`。它检查明确的 5 小时窗口：首次满额发送一次，首次未满则等刷新，之后每轮刷新一次；使用服务端的真实刷新时间，不承诺每条只消耗 1% 或必定改变平台的计时。`scheduler_list` 的 `quotaCycles` 与一次性 `tasks` 分开。暂停、恢复或删除循环须在 `scheduler_action` 传 `targetType: "quota_cycle"`，只支持 `pause`、`resume`、`delete`。开发功能、讨论机制、复制设置不表示启用真实循环。未确认本轮结果时暂停并先核对原对话，不能自动新建规则或换消息再次发送。
- 用户要查看队列：调用 `scheduler_list`。暂停、恢复、取消、删除或重试指定任务时，使用 `scheduler_action`；执行后报告返回的实际状态。`action: "delete"` 会永久删除本地任务记录，只有用户明确授权删除指定任务时才调用，不能因“清理一下”就猜选目标；运行或派发中的任务不能删除。删除不会删除 Codex 对话或撤回已经发送的消息；需要核对的任务可能已发送，删除后不再跟踪结果。功能开发、测试或升级不表示授权删除真实任务。

只将用户授权发送的消息加入队列。讨论插件能力、打开管理器或查看队列本身不表示需要创建任务。恢复额度重试沿用已保存的消息、目标对话和模型；不要为继续运行而改用其他模型、API 账户或付费方式。

此版本只使用 OpenAI / ChatGPT 订阅通道。`scheduler_threads` 返回实际服务商和兼容状态；DeepSeek 或服务商未确认的对话不能发送 GPT 任务，模型名不能切换服务商。先在 Codex 选择 OpenAI 对话后刷新，不要修改全局配置、注入服务商参数或自动重发之前产生 401 的消息。新电脑首次使用时，在 Codex 的本地对话中打开一次管理器以登记宿主连接，随后按管理器的“首次设置与连接自检”完成配置。每位用户使用自己的登录、项目和对话，不复制其他人的凭据与连接登记。

额度等待、对话繁忙、需要用户处理和执行完成是不同状态。桌面发送回执只确认已提交，需由原对话实际执行记录确认完成；连接中断或结果不明时先核对原对话，不自动重发。用户明确要求重试结果不明的任务时，先核对是否已经执行，并说明重复风险，再按 `scheduler_action` 要求传入确认参数。

Windows 后台通过当前用户的按需计划任务运行，没有开机或登录触发器。用户需保持 Windows 登录、电脑未休眠，且 Codex 桌面应用保持运行；关闭管理页或当前对话不影响后台队列。安装后也可双击桌面或开始菜单的“时序任务管理器”，不必向模型发送消息。宿主初始化本插件时自动登记真实连接；断开时先使用管理器的“重新连接”，宿主未提供新连接则重新加载插件。不能把打开页面和发送服务已经连接混为一谈。沿用当前 Codex 登录和所选对话权限，不代为批准后台交互请求。

管理器支持编辑未提交的等待/暂停任务，保存后保留任务身份；复制只填入新草稿，不表示用户已授权再次发送。不要编辑已提交或结果不明的任务。记忆的选择只有项目、对话、模型、思考强度与时区，不保存消息草稿。
