# 0.4.1 连接验证

验证日期：2026-10-29。主机为 Windows 11 x64，Codex 桌面版本 26.1023.6123.0。

## 使用方式

打开管理器后，后台自动检测和重连。首次缺少连接信息时，点击“一键初始化”，会打开 Codex 中的时序插件入口。只有实际连接检查通过才显示“已连接”；打开窗口本身不会被当作成功。无需输入聊天指令，不调用模型进行初始化。

初始化等待最多 60 秒，超时或启动失败可重试。每次点击使用新的初始化编号，已打开的插件入口也会重新检查。普通自动重连不会反复打开 Codex 窗口。

## 验证结果

- 427 项自动测试通过，0 失败、0 跳过。覆盖自动退避、并发检查去重、超时重试、启动失败、停止竞态、旧响应隔离及原生入口复用。
- 本机备份并清空插件连接登记后，通过管理器按钮完成真实首次连接；再次清空后，复用同一原生入口也能一键恢复。
- 两次初始化均通过真实宿主连接读取项目、对话列表和账号额度，并确认发送工具已提供。没有调用发送工具或发送模型消息。
- 原有 10 条任务、设置和循环配置的文件 SHA-256 均保持不变；没有启用真实循环或创建发送任务。验收备份已清理，当前有效连接保留。
- 浏览器验证等待、超时可重试、启动失败、自动恢复、草稿保留和窄窗口布局；模拟场景与真实账号隔离。

最终 Windows x64 离线包已验证空用户目录、系统无 Node、禁止下载仍可用、损坏运行时拒绝，以及删除解压目录后仍能发现六个工具。源码包的生产运行时下载流程也已实际联网验证。发布包以 GitHub Release 的 SHA-256 为准。

## 适用范围

需要安装并登录 Codex 桌面，且已启用本插件。当前原生入口在上述 Codex 版本实测通过；不支持该入口的旧版需要更新，系统禁止打开应用协议时会报错或超时。插件不扫描或猜测桌面管道，不复制其他电脑的连接信息或账号，不修改系统安全策略。

首次连接验收在本机清空登记后完成。第二台实体电脑、ARM64 硬件及本轮新的普通 Windows 账号未实测。真实消息发送沿用原有队列与权限校验，本次未新增模型发送验收。

原生入口使用插件的全局 MCP Apps 入口；参考 [OpenAI Docs：插件扩展](https://developers.openai.com/plugins/build/extensions)。Windows 应用协议及初始化上下文字段同时核对了本机 Codex 实现。
